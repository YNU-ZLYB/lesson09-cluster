## 四、关键结果

### 1. 肘部法则与 k 的选择

`figures/elbow.png`。SSE：800.00 / 644.69 / 513.81 / 434.33 / 366.21 / 317.67 / 280.11 / 257.21 / 236.66。
相邻降幅 155.3 → 130.9 → **79.5** → 68.1 → 48.5 → 37.6 → 22.9 → 20.6，3→4 是斜率变化最大处；
轮廓系数 k=3 为 0.2281、k=4 为 0.2275，几乎持平。**取 k=4**：落在肘部区间内，
且能把"高消费活跃"与"低活跃低消费"分开，业务动作不同（提额 vs 激活）。

### 2. 标准化是必须的（故意实验）

| 指标 | 不标准化 | 标准化后 |
| --- | ---: | ---: |
| 四簇余额极差 | 401,910 元 | 60,072 元 |
| 四簇逾期均值极差 | 0.40 | 2.90 |
| 四簇产品数极差 | 0.80 | 3.90 |

不标准化时余额（十万级）碾压一切，分群退化成"按余额切四段"，逾期、产品数几乎无区分；
标准化之后四维都有区分度，才谈得上"客户画像"。

### 3. 加特征 / 稳定性 / 二维投影

- **加 `account_age_months`**：与原分群 ARI 仅 0.293，结构明显改变——优质客群被"客户关系长度"重新切开
  （老客户低产品 62 人、老客户多产品 49 人、新客户 64 人人均开户仅 45 个月），
  而"高逾期违约风险型"依旧是那 25 人（违约率 84%）。说明开户月数带来的是**生命周期**信息，不是噪声。
- **三种子稳定性**：seed 0/42/2024 两两 ARI = 0.561 / 0.580 / 0.971，风险簇每次都稳定分出 20~21 人（逾期≈3.0、违约≈80%），
  其余簇的人数与边界有小幅流动（低消费簇产品数 2.9 vs 4.2），但业务命名与建议不变。
- **二维投影**：余额×消费平面上四簇高度重叠（`figures/scatter_2d.png` 左），
  产品数×逾期次数平面上风险簇被清楚拉开（右）——真正把客户分开的是"粘性 + 风险"，不是余额。

### 4. 独立研究

- **MapReduce**：见 `research_mapreduce.md`。把"算距离"按样本切片并行、"求均值"按簇聚合，用多轮迭代逼近同一组中心，
  解决数据放不下/算不完的问题；代价是多轮 I/O 与通信，这也是 Spark 改用内存迭代的原因。
- **环形数据**：`make_circles` 玩具数据上 KMeans(k=2) 的 ARI = **-0.002**（完全失败），DBSCAN 的 ARI = **0.997**。
  k-均值用欧氏距离 + 凸簇假设，只能用"直线"切空间；DBSCAN 按密度连通，能把两个环各自圈出来。
- **轮廓系数**：`s=(b-a)/max(a,b)`，a 为到本簇其它点的平均距离、b 为到最近邻簇的平均距离，取值 [-1,1]，越大越"内紧外远"。
  本数据 k=2..8 依次为 0.199 / 0.228 / 0.228 / 0.241 / 0.249 / 0.264 / 0.261，最高在 k=7，
  但它只比 k=4 高 0.037，而 7 个簇每簇仅约 28 人、画像讲不出 7 个不同的故事，所以最终仍取 k=4。
